# Campaign approval and dispatch
Admin reviews a campaign and confirms once. Approval, pause, and resume are persisted in Supabase. The admin tab sends one reviewed draft per API request with a short delay, stopping on error or ambiguous state; this is not a background worker. A closed tab can resume from the saved queue, excluding claimed rows. Only dates 15 minutes to 31 days ahead are eligible. Pause stops new requests; cancellation is separate and only pending schedules are eligible. Provider response and end-to-end schedule creation still need a consenting test account. Do not retry uncertain rows. No actual schedule was created in development. Revocations outside the app and automatic cancellation are not covered; admin must cancel existing scheduled posts and member may revoke provider access.
