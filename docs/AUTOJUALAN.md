# AUTOJUALAN phase 1
One member, one platform; the existing private connection row is the lock. WhatsApp uses documented create/session/poll/connect endpoints. QR tokens stay in the private DB and are never returned to the browser. Member explicitly consents and selects allowed destinations. No scheduling or automatic messages are created by this release. Existing Threads member remains connected. Switching is fail-closed: support must stop schedules and remove the provider account; only confirmed missing accounts unlock. WhatsApp linking is beta and must be tested using a fresh consenting account. Verify provider list and channel response shape in production before offering the service. Do not use a personal account without understanding linked-device access. Expired or uncertain provider sessions may need support.\n
