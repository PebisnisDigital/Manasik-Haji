# UMROH.DIGITAL — v1 lobby preview
New root is a separate 3D educational lobby. Pick avatar, walk via WASD/arrows/touch joystick or auto-approach using program buttons. Two NPCs greet via silent chat, then route-specific registration modal. Form is preview only: no network submission, no persisted personal data, no collection, no payment or access unlock. Program levels are target curriculum, not the new implementation yet. Original home and all earlier simulation routes retained under legacy.html, for beta practice. Do not market as paid access until backend entitlements, admin verification and certificate issuance are implemented and tested. Domain mapping pending owner control. Hajj scope: Tamattu’ introductory route; qualified review required.

## v1.1 — immersive camera and minimal HUD
Lobby uses a close third-person shoulder-offset chase camera, movement relative to camera, free orbit by mouse/touch drag, mouse wheel distance adjustment, eased heading and movement, and camera boom shortened at the back wall. Click/tap NPC or program buttons to auto-approach. Text reduced to a logo, objective, NPC labels and compact program shortcuts; old training/admin links moved into menu, program syllabus collapsed. Natural daylight and textured stone; characters still procedural stylized models, not AAA fidelity. Payment preview remains inactive. Build and browser visual checks separate.

## v1.2 — landscape mobile lobby
Touch devices use landscape-only lobby with a rotate-phone overlay when portrait; pause rendering and movement while blocked. Fullscreen/landscape-lock are attempted only after the user taps, with manual rotation fallback. Independent pointer IDs support left joystick + right/world drag simultaneous camera steering; compact camera reset, program shortcuts, safe-area-aware controls, scrolling landscape modals and mobile pixel-ratio/shadow limits. Desktop remains responsive. Browser/OS support varies (notably iOS may require manual rotation); actual device testing is still required. Applies to the new lobby only, not a completed paid game or all legacy levels.

## v1.3 — free core curriculum preview
Payment deferred. Lobby offers local name (optional), new or resume preview. Separate tenant-scoped state for two core programs; four umrah levels: miqat/ihram direct cards, real existing interactive tawaf (7 laps), short salat/Zamzam demonstrations, interactive sa'i (7 lengths), tahallul demonstration. No quizzes. Umrah completion shows local printable preview certificate. Hajj Tamattu' shares the four preliminary umrah levels, then explicitly waits at the next hajj phase (no hajj certificate yet). Existing legacy games unchanged in scope; core URLs use distinct validated local checkpoint IDs and only advance after the relevant 7-count completion and Continue. This is client-side demo state, not payment access or officially verifiable certification. Landscape gate + fullscreen fallback for new stages and reduced HUD. Mini scenes are illustrative with text fallback; legacy 3D assets retained. Religious/content and real-device gameplay review needed.

## v1.4 — Hajj Tamattu’ curriculum
Core Hajj levels 5–11 added after preliminary umroh: ihram haji, wukuf, Muzdalifah, Aqabah and conditional tahallul/dam guidance, interactive tawaf ifadah and sa'i haji using existing movement engines, Mina and 7 stones per target in order for 11–12 Zulhijah, optional 13th for nafar tsani, tawaf wada. Local certificate only after terminal step 18; existing level-5 Hajj preview checkpoints resume naturally. Dam is educational, not a transaction. Arafah, Muzdalifah, Mina and Jamarat use orbitable illustrative scenes rather than walking avatars; stone preparation is a tap counter. Tawaf wada example includes participants required to perform it and acknowledges exemptions. Actual schedules, variants and rukhsah follow qualified guides; sources https://kemenag.go.id/internasional/mengenal-ibadah-mabit-muzdalifah-dan-mabit-mina-SWLHR and https://sulteng.kemenag.go.id/berita/j96p/puncak-haji%2C-jemaaf-nafar-awal-hari-ini-tinggalkan-mina-sebelum-matahari-terbenam . No payment integration. Tests added, device/gameplay review needed.

## v1.5 — field gameplay
Core Arafah, Muzdalifah, Mina and Jamarat now have moving pilgrim avatars using the baked walk animation, shoulder-offset follow/orbit camera, WASD, independent touch joystick and camera drag, reset camera, distance/ground marker and auto-approach. Stage actions require proximity to the illustrative learning station, Jumrah throws start near avatar and animate to basin while movement is locked. Original legacy site viewer remains unchanged by optional controller. Tawaf and sa'i core camera moved closer; prep, salat/Zamzam and tahallul remain short close-up demonstrations. Geometry simplified; no full AAA assets. No payment enabled. Tests cover safe path geometry; physical device and gameplay tests still needed.

## v1.6 — shared character controls for the remaining core scenes
Miqat and hajj ihram preparation, post-tawaf prayer/Zamzam and both tahallul demonstrations now use the existing third-person walker, joystick, camera drag, marker, pathfinding and proximity-based actions. Prayer animates the walking avatar at the station; Zamzam cup and haircut remain educational props. The prayer station is illustrative, not a real-world qibla finding tool. Legacy mini-scenes remain static when no walk options supplied. No payment changes. Browser gameplay and qualified content review still required.
