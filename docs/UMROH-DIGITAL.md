# UMROH.DIGITAL — v1 lobby preview
New root is a separate 3D educational lobby. Pick avatar, walk via WASD/arrows/touch joystick or auto-approach using program buttons. Two NPCs greet via silent chat, then route-specific registration modal. Form is preview only: no network submission, no persisted personal data, no collection, no payment or access unlock. Program levels are target curriculum, not the new implementation yet. Original home and all earlier simulation routes retained under legacy.html, for beta practice. Do not market as paid access until backend entitlements, admin verification and certificate issuance are implemented and tested. Domain mapping pending owner control. Hajj scope: Tamattu’ introductory route; qualified review required.

## v1.1 — immersive camera and minimal HUD
Lobby uses a close third-person shoulder-offset chase camera, movement relative to camera, free orbit by mouse/touch drag, mouse wheel distance adjustment, eased heading and movement, and camera boom shortened at the back wall. Click/tap NPC or program buttons to auto-approach. Text reduced to a logo, objective, NPC labels and compact program shortcuts; old training/admin links moved into menu, program syllabus collapsed. Natural daylight and textured stone; characters still procedural stylized models, not AAA fidelity. Payment preview remains inactive. Build and browser visual checks separate.
